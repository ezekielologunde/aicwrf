# AI-Integrated Cybersecurity Workforce-Readiness Framework (AICWRF), v0.1

A documented, reusable way for community college and career-technical educators to teach core cybersecurity skills together with AI-security skills, aligned to the NICE Framework.

- `FRAMEWORK.md`: scope, two tracks, modules, assessment, evaluation plan, evidence status.
- `CROSSWALK.md`: course-by-course alignment to NICE v2.2.0 work roles, tasks and the AI Security competency area.

Status: version 0.2, self-published by Ezekiel Ologunde. Not peer reviewed. Not sponsored or endorsed by DoD, NIST, NICE, any military branch or any agency. Not adopted by any institution. Contains no student data.
